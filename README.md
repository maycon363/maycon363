## 🧪 Projetos em destaque

### 🤖 JARVIS — Assistente de IA Pessoal
Assistente pessoal com backend em Python (FastAPI): comunicação em tempo real via WebSocket/SSE, síntese de voz (TTS) com sincronização labial (visemas) para modelos 3D/VRM renderizados em Three.js, transcrição de voz (STT) e memória persistente com Supabase.
🔗 Protótipo público (front-end em Three.js): [ver no portfólio](https://portfolionew-pi-ashy.vercel.app/)

### 🚢 [Batalha Naval — Sistema CRUD Educativo](https://github.com/maycon363/navalremake)
Aplicação CRUD sobre navios: cadastro e consulta de embarcações, cargas transportadas e armamentos configuráveis. React.js, TypeScript, Context API e Framer Motion.
🔗 Trello com o processo e atualizações:
https://trello.com/b/3bMxVzgE/projeto-navalremake

### 🎬 Filmes & Séries
Aplicação para busca e exibição de filmes, séries e atores com integração à API do The Movie Database (TMDb). React, JavaScript e TailwindCSS.
